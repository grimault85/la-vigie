# La Vigie — Guide d'installation

Ce guide explique comment installer et ouvrir **La Vigie** sur votre ordinateur.
L'installation ne se fait qu'une seule fois.

## Sur Windows

1. Double-cliquez sur le fichier **La Vigie Setup.exe** qu'on vous a transmis.
2. Windows peut afficher un avertissement bleu (« Windows a protégé votre ordinateur »).
   C'est normal pour un logiciel récent : cliquez sur **Informations complémentaires**,
   puis sur **Exécuter quand même**.
3. Laissez-vous guider par l'installation (vous pouvez garder le dossier proposé).
4. Ouvrez **La Vigie** depuis le raccourci créé sur le bureau ou dans le menu Démarrer.

## Sur Mac

1. Double-cliquez sur le fichier **La Vigie.dmg** qu'on vous a transmis.
2. Dans la fenêtre qui s'ouvre, glissez l'icône **La Vigie** sur le dossier **Applications**.
3. **Au tout premier lancement uniquement** : ouvrez le dossier Applications, faites un
   **clic droit** (ou Ctrl + clic) sur **La Vigie**, choisissez **Ouvrir**, puis **Ouvrir**
   à nouveau dans la fenêtre qui apparaît. Cette étape n'est nécessaire qu'une fois.
4. Les fois suivantes, ouvrez l'app normalement depuis le Launchpad ou Applications.

## Vos données sont-elles sauvegardées ?

Oui. Dès que vous ajoutez un mois au tableau, **La Vigie enregistre tout automatiquement**.
Vos chiffres sont conservés d'une ouverture à l'autre, sans aucune manipulation de votre part
et sans fichier à gérer.

## Premiers pas

1. Onglet **Compte de résultat** : importez votre **balance** (PDF ou Excel) puis votre
   **caisse** (fichier Excel). Les chiffres se répartissent automatiquement.
2. Cliquez sur **Ajouter au tableau** pour enregistrer le mois.
3. Explorez les onglets **Santé**, **Comparatif** et **Remplissage hôtel**.
4. Le bouton **Bilan du mois (PDF)** produit un document propre à conserver ou transmettre.

En cas de souci, contactez la personne qui vous a fourni le logiciel.
